A flexible and customizable plugin to display various types of notices on the frontend of your WordPress site. Easily configure notice content, appearance, behavior, and display rules through an intuitive admin interface or use a shortcode to place notices anywhere.

## Description

Simple Notice allows you to effortlessly add eye-catching notices to your website. Whether you need to announce important news, promote offers, display alerts, or provide information, this plugin offers a comprehensive set of features to make your messages stand out. Customize notice types (Info, Success, Warning, Error), colors, icons, display positions, and control how and when they appear to your users. Includes a handy shortcode to trigger notices from buttons or links within your content.

## Features

*   **Customizable Frontend Notices:** Display notices globally or on specific pages/posts.
*   **Notice Types:** Choose from Info, Success, Warning, and Error types, each with distinct default styling.
*   **Custom Colors:** Override default type colors with your own background and text color choices using a color picker.
*   **Icon Support:** Add a Dashicon to your notice for better visual communication.
*   **Display Position:** Select from 8 screen positions for your notice (e.g., top left, bottom center).
*   **Flexible Hiding Behavior:**
    *   **Auto Hide:** Automatically hide the notice after a specified delay.
    *   **Click to Hide:** Allow users to dismiss the notice by clicking.
*   **Advanced Display Rules:**
    *   **Show Once Per Session:** Limit notice display to once per browser session.
    *   **Persistent Hide:** If a notice is hidden, keep it hidden for a specified number of days using a cookie.
*   **Shortcode `[smn_notice_btn]`:**
    *   Display a notice when a button or link generated by the shortcode is clicked.
    *   Customize button text, URL, CSS class.
    *   Control notice behavior (auto/click hide, delay, position, style) via shortcode attributes.
*   **Admin Interface:** User-friendly settings page to manage all notice options.
*   **Lightweight & Efficient:** Designed to be performant and integrate smoothly with your theme.

## Installation

1.  Upload the `simple-notice` folder to the `/wp-content/plugins/` directory.
2.  Activate the plugin through the 'Plugins' menu in WordPress.
3.  Go to **Settings > Simple Notice** to configure the global notice options.
4.  Use the shortcode `[smn_notice_btn]` in your posts or pages where you want to trigger notices via a button/link.

## Admin Options Detailed

You can configure the global notice settings by navigating to **Settings > Simple Notice** in your WordPress admin area.

### Content & Behavior

*   **Notice Text:**
    *   **Description:** The main content/message of your notice.
    *   **Type:** Text Input
*   **Notice Icon:**
    *   **Description:** Select a Dashicon to display before the notice text.
    *   **Type:** Select Dropdown
    *   **Options:** None, Info (Outline), Info (Solid), Success (Tick), Warning, Error (Dismiss), Lightbulb, Megaphone, Settings Cog, Star.
*   **Display on Pages/Posts:**
    *   **Description:** Select where the global notice should be displayed.
    *   **Type:** Select Dropdown
    *   **Options:** All, specific Pages, specific Posts.

### Appearance

*   **Notice Type:**
    *   **Description:** Select the semantic type of the notice, which applies default styling (colors, border).
    *   **Type:** Select Dropdown
    *   **Options:** Info (default), Success, Warning, Error.
*   **Notice Style (Base Theme):**
    *   **Description:** Choose a base theme from the underlying `notify.js` library. The Notice Type styling will be applied on top of this.
    *   **Type:** Select Dropdown
    *   **Options:** Bootstrap (default), Happy Blue, Black BG.
*   **Notice Background Color (Overrides Type/Theme):**
    *   **Description:** Choose a custom background color for the notice. Leave blank to use colors from the selected Notice Type or Base Theme.
    *   **Type:** Color Picker
*   **Notice Text Color (Overrides Type/Theme):**
    *   **Description:** Choose a custom text color for the notice. Leave blank to use colors from the selected Notice Type or Base Theme.
    *   **Type:** Color Picker
*   **Notice Position:**
    *   **Description:** Select the screen position where the notice will appear. Default is "bottom center".
    *   **Type:** Select Dropdown
    *   **Options:** Top Left, Top Center, Top Right, Left Middle, Right Middle, Bottom Left, Bottom Center, Bottom Right.

### Hiding & Display Rules

*   **Hiding Behavior:**
    *   **Description:** Choose how the notice can be hidden by the user or automatically.
    *   **Type:** Select Dropdown
    *   **Options:** Auto Hide, Click to Hide.
*   **Auto Hide Delay (ms):**
    *   **Description:** If "Hiding Behavior" is set to "Auto Hide", enter the delay in milliseconds (e.g., 5000 for 5 seconds). Default is "5000".
    *   **Type:** Number Input (conditionally displayed)
*   **Display Frequency:**
    *   **Description:** Controls how often the notice is shown to a user initially.
    *   **Type:** Select Dropdown
    *   **Options:** Show on every page load (default), Show only once per browser session.
*   **Re-show After Hiding (Days):**
    *   **Description:** If the notice was hidden (by click/auto-hide), show it again after this many days. "0" means no persistent cookie (it will re-appear next session/page load based on Display Frequency).
    *   **Type:** Number Input

## Shortcode Usage

The `[smn_notice_btn]` shortcode allows you to display a button or link that, when clicked, triggers a JavaScript notification.

**Available Attributes:**

*   `text`: The text displayed on the button/link itself, and also used as the notice message.
    *   **Default:** "Your button text"
*   `url`: The URL the button/link points to. Use `#` if you only want the button to trigger the notice without navigating.
    *   **Default:** "#"
*   `class`: Custom CSS class(es) to apply to the `<a>` tag for custom styling of the button/link.
    *   **Default:** "smn-notice-btn"
*   `hide_behavior`: Determines how the triggered notice hides.
    *   **Options:**
        *   `click`: Notice hides when clicked. (Default)
        *   `auto`: Notice auto-hides after a delay.
    *   **Default:** "click"
*   `position`: The screen position where the notice will appear.
    *   **Options:** `left top`, `top center`, `top right`, `left middle`, `right middle`, `left bottom`, `bottom center`, `right bottom`.
    *   **Default:** "top center"
*   `style`: The base theme for the notice (from `notify.js`).
    *   **Options:** `bootstrap`, `happyblue`, `blackBg`.
    *   **Default:** "bootstrap"
*   `auto_hide_delay`: The delay in milliseconds after which the notice will auto-hide, only applicable if `hide_behavior="auto"`.
    *   **Default:** 3000

**Examples:**

1.  **Simple notice button:**
    `[smn_notice_btn text="Click Me for Info"]`

2.  **Button triggering an auto-hiding notice with a different style and delay:**
    `[smn_notice_btn text="Limited Time Offer!" hide_behavior="auto" auto_hide_delay="7000" style="happyblue" class="promo-button"]`

3.  **Link triggering a notice that needs to be clicked to hide, positioned at bottom right:**
    `[smn_notice_btn text="View Details" url="/my-details-page" position="bottom right" hide_behavior="click"]`

## Frequently Asked Questions (FAQ)

*   **Q: How do I change the colors of the notice?**
    A: You can set global custom background and text colors in **Settings > Simple Notice > Appearance**. If these are set, they will override the default colors provided by the "Notice Type" or "Notice Style (Base Theme)". For shortcode-triggered notices, custom colors are not currently an attribute; they will use the global settings or type defaults.

*   **Q: How do I change the notice icon?**
    A: In **Settings > Simple Notice > Content & Behavior**, you can select a "Notice Icon" from the dropdown. This icon will appear on the global notice. Shortcode-triggered notices currently display a default "info" style without a specific icon from this setting.

*   **Q: How do the "Display Frequency" (once per session) and "Re-show After Hiding (Days)" rules interact?**
    A: They work together:
    1.  **Persistent Cookie ("Re-show After Hiding"):** If a user hides a notice (or it auto-hides) and you've set a value greater than 0 for "Re-show After Hiding (Days)", a cookie is set. The notice will *not* appear again for that user until that many days have passed, regardless of other settings.
    2.  **Display Frequency ("Once per session"):** If there's no active persistent cookie (either it expired, was never set, or "Re-show" is 0):
        *   If "Show only once per browser session" is active, the notice will appear once. Subsequent page loads in the same browser session will not show the notice.
        *   If "Show on every page load" is active, the notice will appear on each page load (unless a persistent cookie is active).
